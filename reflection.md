While working on this project, I had a general idea of what I wanted to build from the start, but actually turning that idea into a working website was harder than I expected. One of the biggest challenges was writing so many lines of code and keeping everything organized. Small mistakes in HTML caused things to break and i did not know why, and it sometimes took a while to figure out what went wrong.
The hardest part overall was using Git. I ran into multiple issues when trying to push and sync my work, which slowed me down and was frustrating at times. If I do not count Git, adding images to the website was probably the next biggest challenge. Making sure the file paths were correct and that the images showed up properly took a lot of trial and error. Uploading the website to DU’s server was also difficult, especially using the terminal and making sure everything ended up in the right place.
I was able to work through most of these problems by testing small changes, rechecking my file structure, and being patient when things did not work the first time. By the end of the project, I felt much more comfortable with the development process and more confident handling problems on my own.
